# Image Assets Folder (`public/assets/img/`)

Save your photos and project screenshots here using the exact file names below. The portfolio will automatically detect them and display them in the website.

---

### 1. Your Personal Photo (Avatar)
- **File Name:** `avatar.png` (or `avatar.jpg`)
- **Location:** `public/assets/img/avatar.png`
- **What happens:** The site will automatically replace the vector avatar head with your own photo!
- **Cartoon Look:** It will automatically receive the circular editorial border, deep purple drop-shadow, and pop-art contrast filter matching the Robb Owen aesthetic.
- *Tip: If you'd like an illustrated / vector cartoon caricature made directly from your picture, feel free to attach/send your picture in chat and I'll generate the cartoon SVG vector for you!*

### Notes:
- Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`
- High resolution (e.g. 800px × 600px or larger) is recommended.
- If no image is added, the portfolio continues to show the clean vector schematics by default!
